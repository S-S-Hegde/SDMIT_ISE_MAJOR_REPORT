{\LARGE \textbf{ABSTRACT}}
\end{center}
\addcontentsline{toc}{chapter}{Abstract}
\vspace{0.6cm}
VeriProof is a web application built on the MERN stack, it is solving the problem of unverifiable technical skills and fake project claims by providing a centralised platform for portfolio validation and candidate discovery. It combines GitHub repository analysis, plagiarism detection, AI-assisted assessments and analytics for recruiters to ensure authenticity and transparency in the recruitment process.

Its gamified Dynamic Skill Tree, JWT-based authentication, role-based access control (RBAC), and scalable database interactions enable candidates to showcase verified skills and progress, and enable recruiters to assess talent based on credibility, originality, and measurable performance rather than self-reported resumes. The system features an intelligent two-phased assessment engine that dynamically benchmarks candidate competency and generates forensic trust telemetry to protect hiring integrity against generative AI shortcuts and fraudulent claims.

\textbf{Keywords}: Technical Recruitment, Candidate Verification, GitHub Repository Analysis, Plagiarism Detection, Computerized Adaptive Testing, MERN Stack, Skill Tree Progression, Forensic Telemetry.
