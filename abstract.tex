\addcontentsline{toc}{chapter}{Abstract}

\vspace{0.6cm}
\noindent
VeriProof is a web application built on the MERN stack, designed to solve the problem of unverifiable technical skills and fraudulent project claims by providing a centralized platform for portfolio validation and candidate discovery. It combines GitHub repository analysis, semantic plagiarism detection, AI-assisted scenario assessments, and granular recruiter analytics to ensure authenticity, integrity, and transparency in technical recruitment workflows.

\vspace{0.5cm}
\noindent
Its gamified Dynamic Skill Tree, JWT-based authentication, role-based access control (RBAC), and scalable database architecture enable candidates to showcase verified skills through empirical evidence. Simultaneously, recruiters can evaluate applicants based on credibility, originality, and measurable problem-solving performance rather than static self-reported resumes. The platform features an intelligent two-phased computerized adaptive testing engine that benchmarks candidate competency and synthesizes forensic trust telemetry to protect hiring integrity against generative AI shortcuts and credential fraud.

\vspace{0.8cm}
\noindent
\textbf{Keywords}: Technical Recruitment, Candidate Verification, GitHub Repository Analysis, Plagiarism Detection, Computerized Adaptive Testing, MERN Stack, Skill Tree Progression, Forensic Telemetry.
